# 小红书更新监控 v1.1.5

发布时间：2026-10-24 00:07:40（北京时间 UTC+08:00）

## 本次更新

- 修复内嵌小红书页面已登录，但面板长期显示未登录或HTTP验证中的状态不同步问题：有效的日常采集结果会自动同步登录状态，无需额外发送验证请求。
- 区分验证排队、请求冷却、实际HTTP验证和验证超时；账号菜单显示等待原因及可重试时间，验证受限后不再一直停留在验证中。
- 验证期间保留已获取的当前账号名称；页面未返回账号资料时，不再因成功验证而清空已有账号信息。
- 为验证任务增加超时和取消处理，忽略Cookie变化前的旧验证及旧采集结果，避免旧请求覆盖新会话状态。
- 保持现有请求间隔、冷却和账号限制规则；日常采集成功不会重置全部博主排程，账号受限时仍需手动验证后恢复。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.5.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
