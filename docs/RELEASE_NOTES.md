## 本次更新

- 发现软件新版本时，在“关于与更新”右侧显示红色“新”提示，并弹出应用内更新确认框。
- 更新弹窗与“关于与更新”页面同步展示新版本更新内容，以及GitHub实际发布时间（北京时间）。
- 支持显示下载进度、稍后更新和下载完成后手动重启安装；同一版本在本次运行内不重复弹窗。
