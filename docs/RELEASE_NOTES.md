# 小红书更新监控 v1.1.3

发布时间：2026-10-20 17:23:13（北京时间 UTC+08:00）

## 本次更新

- 修复点击Windows通知后打开Electron欢迎页：正式版启动时核验并修复本软件的快捷方式、通知标识和启动目标，绑定安装后的程序。
- 开发版与隔离测试使用独立通知身份，默认不注册原生通知，防止测试进程覆盖正式版启动注册。
- 新增持久化通知激活处理，支持软件重启后查看更新；关闭提醒只确认对应通知中的记录，不清除后来新增的提醒。
- 升级后一次性刷新本软件遗留的Windows系统通知，保留本地更新记录并重新显示待确认提醒，避免旧通知继续唤起开发程序。
- 通知跳转等待主界面就绪，统一进入更新记录；去除原生全局回调与实例事件造成的重复处理。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.3.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
