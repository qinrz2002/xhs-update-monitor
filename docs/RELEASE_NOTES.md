# 小红书更新监控 v1.1.4

发布时间：正式发布后自动记录

## 本次更新

- 修复自动更新进度从0到100重复两次：自定义安装器改为一次完整下载，避免差量更新因外层安装包与内层缓存不匹配而失败后重新下载。
- 明确区分下载和校验阶段：传输结束后显示正在校验，校验通过后才允许重启更新；忽略完成后的迟到进度事件，避免状态倒退。
- 点击重启并更新后立即显示准备安装动画，关于与更新页和更新弹窗两个入口保持一致，防止重复触发安装。
- 新增独立的自动更新安装进度窗口：主程序退出后仍显示循环动画、实际文件处理进度和百分比，安装成功后自动关闭并打开新版；失败时保留错误提示。
- 修正安装进度窗口圆弧的几何中心与旋转中心，使加载动画在背景方块内居中；支持系统减少动画偏好。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.4.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
