# 小红书更新监控 v1.1.2

发布时间：正式发布后自动记录

## 本次更新

- 所有curl业务统一串行限频，请求结束后随机等待30～90秒，同一博主至少间隔5分钟；新增滚动每小时60次、每日500次的总量限制。
- 限流后至少冷却30分钟，重复失败指数退避并遵守服务端Retry-After；计数、冷却和账号阻断保存到本地，重启不会清零。
- 搜索、主页、短链接或验证发现账号异常、验证码或登录失效，联动停止全部curl采集，不再自动重复登录；处理后需手动验证。
- 合并并发会话验证，curl响应的Cookie轮换不再触发额外验证请求；补全接收类型和语言声明，保持登录与采集的User-Agent一致。
- 新增不含完整链接、用户ID、搜索词、Cookie和签名的本地请求日志；详细记录限频策略及其适用范围，不承诺规避平台风控。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.2.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
