# 小红书更新监控 v1.0.0

Windows 桌面版首个正式发布版本。

- 支持多个博主主页监控、编辑、暂停和删除。
- 支持链接添加与纯 curl 名称搜索，展示真实昵称和头像；搜索候选可打开内嵌主页核对。
- 支持基础检测间隔与随机浮动、更新记录、文章列表、Windows 通知及循环提示音。
- 支持亮色与暗色主题，JSON 与加密登录信息保存在程序旁的 data 目录。
- 启动后及每小时检查 GitHub 正式 Release，自动下载新版，手动确认重启安装。
- 现代安装器支持自定义位置、真实百分比进度、深色确认卡片以及安全退出后台后继续安装。

下载并运行 `XhsUpdateMonitor-Setup-1.0.0.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留 data；建议更新前备份。

当前发布未使用商业代码签名证书。平台变化、登录失效或安全验证可能导致采集失败；首页文章列表不保证包含完整历史。跨版本线上自动更新仍需后续正式版本验证。
