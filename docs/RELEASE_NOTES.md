# 小红书更新监控 v1.1.1

发布时间：2026-10-18 21:31:22（北京时间 UTC+08:00）

## 本次更新

- 修复旧文章补入近期列表时被误判为更新：未见过的笔记ID不再直接视为新发布，结合已保存的发布时间边界判定。
- 每位博主持久保存已确认的最新发布时间，删除最新文章、重启软件、编辑同一博主或撤销删除均不会让边界倒退。
- 更早文章、旧文重新置顶及恢复显示只同步到文章列表，不触发新文章提醒；发布时间缺失、异常或历史边界未确认时不推测提醒。
- 兼容已有本地JSON基线；同一批中正常新文章仍单独提醒并去重，采集不完整或仅刷新资料不会提前推进判新边界。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.1.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
