# 小红书更新监控 v1.1.0

发布时间：正式发布后自动记录

## 本次更新

- 主界面全面改版：统一亮暗主题、图标、间距与控件样式，顶部四张统计卡的图标垂直居中。
- 博主列表使用完整内容宽度；检测与提醒设置改为侧边抽屉，账号登录与验证操作整合到右上角账号菜单。
- 统计卡支持点击或键盘跳转到相应列表、更新记录及提醒中心，新增本地名称筛选和运行中筛选。
- 博主行保留检测与文章入口，暂停、设置和移除整合到更多菜单；删除确认与撤销、高亮清除行为继续保留。
- 新增页面、抽屉、弹窗、菜单及列表过渡动画，搜索、检测和会话验证提供任务加载反馈；支持系统减少动画偏好。
- 完善首次使用、无匹配结果、暂停与账号受限状态，修正统计和下一次检测显示，普通状态刷新不会重复播放列表动画。
- 保留纯curl采集与名称搜索、本地JSON和加密登录态、Windows提醒、循环声音及每小时正式Release自动更新机制。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.1.0.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
