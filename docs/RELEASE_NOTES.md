# 小红书更新监控 v1.0.2

发布时间：正式发布后自动记录

## 本次更新

- 博主列表单击任意博主行后清除原有的红色定位高亮；点击行内操作仍正常执行，刷新后高亮不会重新出现。
- “关于与更新”中的“检查更新”和“重启并更新”按状态互斥显示：下载完成后仅显示重启更新按钮。
- 两个更新操作按钮统一尺寸、字体及居中样式，亮色和暗色主题保持一致。

## 安装与更新

下载并运行 `XhsUpdateMonitor-Setup-1.0.2.exe`。`latest.yml` 和 `.blockmap` 用于软件自动更新，无需手动打开。升级保留程序旁的 data 文件夹；建议更新前备份。
